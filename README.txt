BLKASEM PROJECTS - NETLIFY ONLY

This package is ready for Netlify as a static website.

Important:
- It does NOT use Flask.
- It keeps the dark/blue/cyan BLKASEM PROJECTS style.
- The site can be deployed directly to Netlify.
- A real secure admin login + real file uploads cannot be provided by HTML/CSS alone.
- If you need real uploads/admin, a backend or storage service is required.

How to deploy:
1. Open Netlify.
2. Upload the contents of this folder (or connect the folder/repository).
3. Netlify will publish index.html.

The current page contains the frontend/admin interface, but backend API calls are disabled unless a backend is connected.
